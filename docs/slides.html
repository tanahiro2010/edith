顔・名前・前回の話が覚えられない——そんな僕みたいな人のための、スマートグラス向け「社会的記憶」補助AI。

なぜ作ったか

ほとんど覚えていない。

  • 1
    名前も所属も出てこない顔は分かる。でも「どなたでしたっけ」が本当に言えない
  • 2

  • 3

人と会って話すこと自体が、僕には地味にしんどい。これを何とかしたくて作り始めた。
What is E.D.I.T.H

Enhanced Data · Identity · Timeline Helper

…というのは後付けのこじつけ。元ネタはアイアンマンのスマートグラス “Even Dead, I'm The Hero”。かっこいいので勝手に拝借しました。

記憶を AI が拡張する補助システム。グラスは薄い「表示・センシング端末」に徹し、 顔認識・音声理解・記憶といった知能はバックエンドに置く。 だから実機が無くても先行開発できる。

薄い端末

グラスは映像表示とカメラ/マイクのセンシングに集中。

知能はクラウド/ローカル

顔認識・STT はローカル、意図理解の LLM のみクラウド。

当面の目標 Lv.1

顔認識 → 名前を HUD に表示する体験の完成。

Concept

Recognize → Remember → Assist

Recognize — 誰か分かる

顔認識で目の前の人を識別し、名前を HUD に表示。

Remember — 思い出す

過去の会話ログを要約・記憶し、前回の話題を呼び戻す。

Assist — 会話を助ける

自然言語で「さっき何を話した？」に即答する。

Architecture

4つの疎結合マイクロサービス

すべて HTTP/JSON。クライアントを Mac → スマホ → Halo と替えても中身は不変。

CLIENTNative ClientFlutter / Halo — HUD描画・カメラ・音声
⇅ HTTP / (将来 WebSocket)
済Voice AgentTS / Hono :8010 — 指示理解・Tool Calling・記憶
済STT Servicefaster-whisper :8020 — ローカル文字起こし
済Face APIFastAPI + insightface :8000 — 顔登録・識別
CLOUDLLMdeniai gpt-5.2 — 意図理解・応答生成
⇅
PostgreSQL :5433 — 会話/記憶 PostgreSQL + pgvector :5432 — 顔embedding
Processing Flow

例）「この人を田中さんとして覚えて」

音声入力→ STTローカル whisper→ LLM が意図理解Tool Calling→ register_person
↳ capture_face を Client へ→ 端末カメラで撮影→ Face API に登録→ HUD「登録しました」

明確なコマンドは即実行

「記録開始/終了」は LLM を介さず決定的に処理 — 低レイテンシ・低コスト。

それ以外は Tool Calling ループ

LLM が必要なツールを選び、結果を受けて自然言語で応答する。

やすみ？— 今日、学校ある？を自動で。

気象庁の警報と、各学校の規則をもとに「今日は登校か休校か」を毎朝自動で判定して LINE で知らせる LINE ミニアプリです。 台風や大雪の朝、学校の判断を待たずに自分の予定が立てられます。

判定は5パターン

通常登校 / 自宅待機 / 午前休 / 午後から登校 / 全日休校。
登録した地域・警報・判定時刻にあわせて、決まった時刻に自動で判定します。

同じ学校のみんなで規則を共有して使えます（学校公式のサービスではありません）。

3ステップで、いま無料

対象地域・警報・判定時刻を登録するだけ。LINE ミニアプリなのでアプリのインストールは不要です。
